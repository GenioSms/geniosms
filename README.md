GenioSms is a sms gateway app

Get gateway sms app from Google play store https://play.google.com/store/apps/details?id=com.diocle.geniosms

Sign-in https://geniosms.net/?a=panel

Pair app, insert pin into app

Get api key from panel list

Get Ipn for notification sent and delivery sms

For more info view guide at https://geniosms.net/?a=site&b=guide&c=home
